## Технологии

* **Язык программирования:** Java 17+
* **Тестовый фреймворк:** TestNG
* **Сборка проекта и зависимостей:** Maven
* **Браузеры (UI):** Chrome, Firefox, Edge, IE
* **Отчеты:** Allure

## Установка и запуск

### Клонирование репозитория

1. Сначала клонируйте репозиторий:
   ```bash
   git clone https://github.com/kultyapka3/java-ui-autotests.git
   ```

2. Перейдите в нужную директорию:
   ```bash
   cd java-ui-autotests
   ```

### Сборка проекта

Для загрузки зависимостей и компиляции выполните:

```bash
mvn clean compile
```

    1. Открыть браузер
    2. Перейти по ссылке: `https://www.way2automation.com/angularjs-protractor/registeration/#/login`

- **Шаги**:
    1. Ввести в поле `Username` тестовое значение

    1. Валидные данные:
        - `Username` — `angular`
        - `Password` — `password`
        - `Username *` — `Hero`

    2. Невалидные данные (неверный логин):
        - `Username` — `invalid`
        - `Password` — `password`
        - `Username *` — `Hero`

    3. Невалидные данные (неверный пароль):
        - `Username` — `angular`
        - `Password` — `invalid`
        - `Username *` — `Hero`

    4. Пустой логин:
        - `Username` — ` `
        - `Password` — `password`
        - `Username *` — `Hero`

    5. Пустой пароль:
        - `Username` — `angular`
        - `Password` — ` `
        - `Username *` — `Hero`

    6. Пробелы в логине и пароле:
        - `Username` — `   `
        - `Password` — `   `
